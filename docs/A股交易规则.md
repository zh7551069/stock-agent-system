# A股交易规则（制度铁律 · 常驻 L0）

> ⚠️ **本文件是「规则」，不是「数据」。**
> 规则 = 制度事实，永不改变（除非交易所改制度）→ **无条件生效，不得从数据推断或降级**。
> 数据 = 逐日事实（交易日历、行情）→ 查询，缺失时**阻塞**（不给建议），而不是猜。
>
> 教训来源：`evidence/quant-asset-inventory.md` §「T+1 写在日记里 = 没写；把不变的规则放进会变的存储里，必然忘记」。
> **规则必须落到代码校验上，只写文字等于没落。**

## 1. 交易时间（连续竞价）

| 阶段 | 时间 | 规则 |
|---|---|---|
| 集合竞价（开盘） | 09:15–09:25 | 09:20 后不可撤单 |
| 连续竞价 | 09:30–11:30 / 13:00–15:00 | 正常成交 |
| 收盘集合竞价 | 14:57–15:00（沪深） | 深市 14:57–15:00，沪市同 |
| 盘后固定价格交易 | 15:05–15:30（科创板/创业板） | 以收盘价成交 |

## 2. T+1（永不改变的铁律）

- **当日买入的股票，当日不能卖出**，最早**次一交易日**才能卖。
- **当日卖出所得资金，当日可用于买入**（资金 T+0，股份 T+1）。
- 代码校验意义：回测/建议里，`sell_date > buy_date` 必须成立；`sell_date == buy_date` 是**非法交易**，必须报错或剔除，而不是默默计入收益。
- ETF / LOF / 可转债：T+0（当日可卖），但**股票是 T+1**，不要混。

**校验意义**：回测里若按「股数」下单，必须校验 `shares >= min_lot` 且 `shares % lot_step == 0`；否则这笔交易**根本不可能成交**，不能计入收益。

## 4. 涨跌停幅度（按板块）

| 板块 | 涨跌幅限制 |
|---|---|
| 沪深主板 | ±10% |
| 创业板（2020-08-24 起） | ±20% |
| 科创板 | ±20% |
| 北交所 | ±30% |
| ST / *ST | ±5%（主板）；创业板/科创板 ST 为 ±20% |
| 新股上市首日 | 主板：44% 上限 / 36% 下限（2023 注册制后调整）；科创/创业板：无涨跌幅限制前 5 日 |
| 退市整理期 | ±10%，30 个交易日后摘牌 |

**校验意义**：`limit_price` 表若缺失某日涨跌停价，**必须阻塞**，不能用「昨收 ×10%」猜（ST/创业板/新股都不同）。

## 5. 最小价格变动单位（tick）

- 沪深股票：**0.01 元**
- 科创板：0.01 元
- 北交所：0.01 元
- 基金：0.001 元（部分）
- 可转债：0.001 元

## 6. 交易费用（回测成本口径）

| 费用 | 费率 | 方向 |
|---|---|---|
| 佣金 | 约 0.025%（万 2.5），最低 5 元 | 买卖双向 |
| 印花税 | 0.05%（千分之 0.5） | **仅卖出** |
| 过户费 | 0.001%（万分之 0.1，沪深） | 买卖双向 |

**往返成本约 0.15%**（判决器 `COST_RATE=0.0015` 的出处），净收益 = 毛收益 − 0.15%。

## 7. 停牌 / 复牌

- 停牌期间**不能交易**：回测里若某日停牌，`suspension` 表该日必须命中，否则会把「停牌日」当成可交易日算收益。
- 停牌期间**不计入持有天数**？——计入（T+1 从买入日起算），但**不能卖出**。

## 8. 除权除息

- 分红/送转/配股会导致**价格跳空**，必须用**前复权价**计算收益（本项目用 `tech_factor_qfq`，不用 `daily` 原始价）。
- 复权因子口径：本项目 `adj_factor` / 「复权因子」zip 是**错表**（hfq=6.25 vs 权威 8.6463），**弃用**；用 `tech_factor_qfq.close` / `tech_factor_hfq.close`。

## 9. 规则校验的落地要求

**不能只在文字里描述，必须落到代码**：

1. 回测引擎：`sell_date > buy_date` 断言（T+1）。
2. 下单量：`shares >= min_lot` 且符合 `lot_step`。
3. 涨跌停：`limit_price` 缺失时阻塞，不猜。
4. 停牌：`suspension` 命中时该日不可交易。
5. 成本：往返 0.15% 必须扣。

> 任一规则缺失 → **阻塞出结论**（不是降级、不是假设、不是跳过）。
