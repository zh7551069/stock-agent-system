# 决策生命周期

主控规划 → 回测验证 → 对账归因 → 进化回滚。一条策略从触发到复盘、再到进化的全链路——**每一步同时活在「可观测」与「自进化」两条纵贯线上**。

```mermaid
sequenceDiagram
    autonumber
    participant S as 盘中哨兵
    participant C as 主控
    participant A as 调度器 / 策略师
    participant B as 回测判决官
    participant R as 对账官
    participant G as 资产登记官
    participant T as Trace 总线
    participant E as 因子工坊 / 能力管家

    S->>C: 异动 / 信号触发事件
    C->>A: 理解意图 → 规划 → 派单
    A->>A: 起草(Flash) → 定稿(Pro)
    A->>B: 提交 proposal（机器可读）
    B->>B: 回放验证：独立日超额 / 配对检验
    alt 不通过
        B-->>A: 打回（带证据）
    else 通过
        B-->>C: 通过：超额 + 概率 + 分层结论
        C->>C: 整合 → 组装决策包（仓位 / 风控）
    end
    Note over C,T: 全程每回合产出 span → Trace 总线（四元 id + 三层语义）
    Note over C,R: T+N 收盘后
    C->>R: 决策包 + 实际成交 → 对账
    R->>R: 逐条复盘抓手/依据 → 沿溯源图归因（结果归因）
    alt 归因指向策略/因子
        R-->>E: 归因结论 → 换因子集/改定义/调参数/调权重/改出场
        E->>B: 新 proposal → 影子回放 + 配对检验
        B-->>E: 晋级 / 回滚（更差即回滚）
    else 归因指向过程
        R-->>G: 过程评估 → 改 prompt/skill/协议（三重门控）
    end
    C-->>G: 全程 trace + 蒸馏 → 意图-经验-效用三元组 + 溯源边
    G-->>G: 供会话评估 + 效用检索
```

## 十二步走（含进化回路）

1. 盘中哨兵捕获异动/信号 → 2. 主控理解意图、规划、派单 → 3–4. 策略师生成 proposal（Flash 起草、Pro 定稿）→ 5. proposal 交给回测判决官 → 6. 回放验证（独立日超额、配对）→ 7. 不通过则带证据打回 → 8. 通过则主控整合 → 9. 组装决策包（仓位/风控）→ 10. T+N 收盘对账，沿溯源图**归因** → 11. 归因落到策略/因子或过程，**进化**（影子回放/三重门控）→ 12. 晋级或回滚。

全程每回合产出 span → Trace 总线；蒸馏 → 意图-经验-效用三元组 → 供会话评估与效用检索。

> 关键：第 10–12 步是可观测（trace）→ 归因（溯源图·信用传播）/ 评估（评估器）→ 进化（回灌可进化层）的闭环，把「复盘」从一次性的动作变成了**持续进化的输入**。
