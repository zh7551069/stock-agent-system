# 落地路线（先判决器，后决策面）

「可观测」与「自进化」两条纵贯线**从 P0 就贯穿，不是到最后才加**：判决器（冻结层）先立，观测底座同步铺，进化门禁随评测平台一起落地。

| 阶段 | 做什么 | 完成判据 | 可观测纵贯线 | 自进化纵贯线 |
| --- | --- | --- | --- | --- |
| P0 判决器 | 回测判决官 + 对账官 + 数据口径契约 + Trace 总线 | oracle 测试能识别正 alpha；独立日 ≥30；配对检验可用 | Trace 总线 + 三层语义 + 四元 id + 前缀门禁 | 冻结层先立（判决器/口径/回测引擎） |
| P1 资产 | 数据管家、知识馆长、能力管家、协议注册表 | 口径注册率 100%；知识卡带证据等级；未考证数据拒入 | 检索 / 取数 span 入总线 | 可进化 B（知识卡/口径/skill）就位 |
| P2 决策面 + 主控 | 主控、调度器、策略师、因子工坊、大盘分析师、盘中哨兵 | 主控规划可落地；proposal 可被判决官直接消费 | 8 类 Span 全覆盖；决策包带概率置信度 | 可进化 A（策略/因子）就位，因子 4 类动作可执行 |
| P3 评测平台 | 采集/评测/反馈三层 + 过程资产 + 会话评估官 + 影子回放门禁 | 任意决策可回放；A/B 回归门禁生效 | 三阶段评估 + 定向观测 + logprobs 置信度 | 影子回放门禁 + 三重门控 + 溯源图归因 |
| P4 自我进化 | 全链路闭环 | 过程变更皆有证据，更差自动回滚 | token 级 trace + 指标归因 + 实验 | 意图-经验-效用 + 效用检索 + 双环闭环 |

> 每阶段的「完成判据」都同时含一条观测判据和一条进化判据，缺一不算该阶段完成——这正是「横切」的含义：两条线不是附加项，而是每个阶段的验收标准。
