# 多 Agent 交互协议约定（任务 8）

协议是**版本化治理工件**，不是某个 Agent 每次临场决定的东西。设计一次、机器校验、违规即告警。

> **谁来定义、谁执行、谁校验**：协议由**人（系统设计者）在设计期一次定义**——这不是任何运行时 Agent 的职责；运行时由**调度器执行**、**协议总线机械校验**（进总线即校验）、**裁决面对账官/会话评估官做语义校验**；要改协议只能走**过程进化**（会话评估官评估 → 能力管家提案 → 三重门控 → 发布/回滚），不能由 agent 临场改。

| 协议层 | 内容 | 校验方 |
| --- | --- | --- |
| 消息信封 | 四元 id + 来源/目标 agent + 消息类型 + schema 版本 + 时间戳 + 幂等键 | 协议总线（进总线即校验） |
| 消息类型 | 事件 / 命令 / 请求-响应 / 发布-订阅，各带优先级与超时 | 调度器 |
| 决策包契约 | 策略 proposal 与决策包是机器可读 JSON Schema：信号/进场/出场/仓位/风控门/每个抓手与依据的引用 | 回测判决官 + 对账官 |
| 数据口径契约 | 复权基准、单位、日期格式、涨跌停、T+1、板块归属，全部带 id 与版本（v1 见 [数据口径契约](/caliber-contract.html)） | 数据管家 |
| 写域隔离 | 每个 Agent 只写自己的状态；裁决面只读生产；评测平台只写过程配置仓 | 协议总线（ACL） |
| 异步/同步 | 盘中路径同步低延迟；盘后/回测/对账/评估走异步队列 | 调度器（预算与限流） |
| Trace/Span 契约 | 8 类 Span 类型（回合/模型调用/数据取数/工具调用/检索/风控校验/判决/事件）+ 三层语义（`trace.*`/`trad.*`/`a股.*`）+ 前缀白名单门禁 | 采集层（进总线即校验） |
| 评估器 DSL 契约 | 判定侧（判决器/对账官/会话评估官）只声明变量，DSL 表达式从 span 取值（`spans[name=="x"].output`），选手改字段不改判定侧 | 对账官 + 会话评估官 |
| 进化动作契约 | 因子工坊 4 类动作（add/remove_factor、edit_definition、tune_params、reweight）+ 每动作必须带归因证据 id | 回测判决官（影子回放前校验） |

> 三条横切线各自落到协议上：**可观测 = Trace/Span 契约 + 评估器 DSL 契约**；**自进化 = 进化动作契约**。协议是这两条线「机器可校验」的落点。
