# 风险与反模式（来自已踩过的坑）

| 反模式 | 后果 | 对策 |
| --- | --- | --- |
| 判决器与选手共模 | "测试全过但决策没用" | 物理隔离 + 只读 + 独立样本定义 |
| 用交易笔数当样本 | 自由度虚高、t 值假显著 | 以日为样本，配对对齐日期 |
| 未剔 beta 就报超额 | 把 beta 当 alpha | 超额对沪深300剔 beta，配同天随机对照 |
| 数据口径漂移 | 前复权 vs 涨跌停价、元/万元、东财 vs 同花顺混用 | 口径契约 + QC 门禁 |
| 为一点风险否决全部 / 为一点机会否决卖出 | 错失机会或错过离场 | 概率权重判断，判决器输出概率而非二元 |
| 主控越权直接写生产 | 规划层污染生产数据 | 主控只规划整合，写域由 ACL 强约束 |
| 用模型自评当奖励（Reward Hacking） | 自进化朝错误方向狂奔 | 奖励 = 可机器验证的真实结果（T+N 超额 / 配对 vs 随机对照），判决器先行 |
| 评估器自己在 good/bad 间来回翻 | 判决器噪声，回滚误判 | 标签 token 的 logprobs 判置信度，低置信升级精判 / 人工复核 |
| 把「时间顺序」当「因果来源」 | 归因归到刚好相邻的错误节点 | 沿溯源图依赖边做多步结构归因（信用传播），用图距离而非时间间隔 |
| 进化污染判决器 | 重蹈「测试全过但决策没用」 | 冻结层（判决器/口径/回测引擎）与可进化层分离；进化只发生在可进化层 |
| span 缺失 / 口径不合法 | 归因无据、回放失败 | 前缀白名单门禁 + 采集层机械拦截（进不了判决器） |
| 指标被全样本稀释（未分层） | 假结论（如 9 信号都不 beat 随机篮） | 定向观测按 regime 圈选切片再下结论 |
